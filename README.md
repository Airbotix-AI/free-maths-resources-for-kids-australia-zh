## 使用方式

本仓库正文为简体中文；外部资源有各自的语言支持。本指南的中文翻译不代表外站课程也有中文版。国际资源按数学专题选择，不默认符合澳洲课程。

官方来源支持免费范围说明。本次未创建孩子账号、购买订阅、完成整门课程或逐一运行所有互动。每次先选择一个模型，让孩子解释，再检查结果。
